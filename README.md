# Atlas Shader Emporium
Repository of all my shaders, including recreated Vertigo 2 shaders

** **

# INSTALL DIRECTIONS
## Installing Atlas's Shader Emporium is simple. 
Copy This: 
```text
https://github.com/Atlas966/Atlas-Shader-Emporium.git
```
Open Unity, head to Window > Package Manager

<img width="420" height="546" alt="image" src="https://github.com/user-attachments/assets/f7553b3e-accc-4af3-bcac-a2c1dc0bf99d" />

Press the `+` icon, `Add package from git URL`
<img width="1198" height="602" alt="image" src="https://github.com/user-attachments/assets/850b0fdf-6158-418e-8346-8439ebaf60bc" />

Paste the git URL and press `Add`
<img width="1196" height="382" alt="image" src="https://github.com/user-attachments/assets/4003cb1a-8929-47d6-a09b-cb2476f167fe" />

Wait for Atlas's Shader Emporium to install
** **
After installed, Atlas's Shader Emporium can be found at `Packages/com.atlas.atlasshaderemporium`

<img width="291" height="127" alt="image" src="https://github.com/user-attachments/assets/74e6c87d-38da-4042-9213-60b35de25fe9" />

**Congrats**, you installed Atlas's Shader Emporium.
